# Live 图片活动行预览设计

> 日期：2026-08-13
> 状态：已确认

## 目标

Live 模式下，用户把光标移动到 Markdown 图片语法所在行时，既能编辑源码，也能继续看到图片，交互与 Obsidian 类似。

## 行为

- 非活动图片行：图片语法被图片 widget 替代，只显示图片。
- 活动图片行：保留完整 `![alt](assets/...)` 源码，并在该行下方显示图片预览。
- 多行选择覆盖图片行时，也视为活动行，显示源码和下方预览。
- 光标离开图片行后，恢复为只显示图片。
- 双击非活动图片时，将编辑器选区定位到图片所在行，立即进入“源码 + 下方预览”状态。
- 图片缺失或尚未同步时，下方显示现有缺失占位。
- Source 模式始终只显示 Markdown 源码；Preview 模式行为不变。

## 实现

在 CodeMirror Live Preview 插件中复用现有 `ImageWidget`：

- 非活动行继续使用 `Decoration.replace` 替换图片语法。
- 活动行使用 `Decoration.widget({ block: true, side: 1 })`，把预览作为视觉块放到行尾。
- widget 不写入文档、不增加真实换行，因此不会改变保存内容、光标位置、行号或撤销历史。
- 图片资源仍由父页面读取并通过 `setImageAssets` 消息提供 data URL。

## 验证

- 单光标进入和离开图片行时，两种显示状态正确切换。
- 跨行选择覆盖图片行时显示源码和预览。
- 本地图片、外链图片和缺失图片行为一致。
- Source/Preview 不发生回归，单元测试与生产构建通过。
